# hbench-datasets

Benchmark datasets for [hbench](https://github.com/node-q/hbench), published as signed OCI
artifacts: one artifact per dataset version, one reproducible layer per task, verified by digest
before hbench unpacks it.

Being set up: nothing is published yet.

The tooling in this repository is Apache-2.0 (`LICENSE`). Each dataset keeps its own licence,
named with the dataset.
